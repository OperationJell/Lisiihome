LISII HOME 0.1.0 — первая сборка Windows x64

1. Установите LISII-HOME-Setup-0.1.0.exe.
2. Запустите LISII HOME.
3. Для знакомства: «Пока побыть дома без подключения».
4. Крыша — перемещение, колесо — размер, мебель — действие.
5. Клик по своему персонажу — настроение, по коту — «Эу».

Для двоих в одной сети: на первом ПК запустите дополнительный ярлык
LISII HOME Server из меню Пуск. Он покажет адрес сервера.
Первый игрок создаёт комнату за девушку, второй входит по коду за парня.

Для подключения из разных сетей нужно отдельно разместить сервер.
Публичный сервер и адрес обновлений в этой поставке НЕ настроены.
Код сервера, Docker и подробные инструкции — в архиве исходников.

Установщик собран, но запуск на Windows в этой среде не проверен.
Это предварительная версия без сертификата подписи издателя.
